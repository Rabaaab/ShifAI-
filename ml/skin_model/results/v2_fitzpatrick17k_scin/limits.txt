LIMITS. This model is a screening hint, not a diagnosis, and must never be presented as one. It was trained on a very small dataset: 24 acanthosis nigricans images in total (train/val/test = 16/4/4), from: Fitzpatrick17k, SCIN (see dataset_sources.csv for licences). The test set has only 8 images, so the test AUC of 0.437 (95% bootstrap CI 0.000-1.000) is uncertain. By skin tone: Fitzpatrick III-IV: n_AN=4, AUC=0.437, sensitivity=0.750 (3/4). No acanthosis nigricans test images in: Fitzpatrick I-II, Fitzpatrick V-VI, so performance there is unknown. Each skin-tone subgroup contains only a handful of positive images, so these subgroup numbers are indicative at best; performance on darker skin, which matters for a Moroccan audience, is not established. The negative class contains other skin diseases only, no photos of normal skin. Part of the data are smartphone photos (SCIN: 0 AN test images), but not specifically of the neck, so real-world accuracy in the app may still be lower. Before any real use, the model needs a larger, consented, tone-balanced dataset collected with phones, and clinical validation.
